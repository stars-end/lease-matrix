# Lease Matrix

Local-first, spreadsheet-like workspace for comparing multiple vehicle lease offers side by side.

Status: pre-build (Milestone 0 not started). The v0.1 implementation contract is [spec.md](./spec.md); open corrections and architect questions are tracked in [SPEC_ERRATA.md](./SPEC_ERRATA.md).

- All calculations are estimates.
- Not affiliated with Leasehackr or Edmunds. No scraping: Leasehackr Calculator URLs are parsed locally in the browser.
- Deal data stays in your browser in v0.1 — no account, no cloud storage, no analytics.
