## Summary

Implement Lease Matrix v0.1 end-to-end per `spec.md`: pnpm/Turbo monorepo, pure domain + lease-engine packages, AG Grid Community workspace, Leasehackr URL interop, full test pyramid (unit/golden/integration/Playwright), and deploy one stateless web service to a **Railway dev environment** via `.railway/railway.ts` IaC with runtime SHA deploy proof.

## Problem

The spec (4,500+ lines) is approved and amendment-complete but unbuilt. Risks concentrated in: (a) lease-math correctness (sign/rounding semantics), (b) unvalidated-then-validated Leasehackr parameter map, (c) IaC-only Railway path never exercised on this machine for this repo. This plan sequences the build so each risk is retired behind an explicit gate.

## Goals

1. Green monorepo passing `pnpm verify` (format, lint, typecheck, unit, build, Playwright e2e).
2. Lease engine proven by ≥6 hand-authored golden fixtures + architect-mandated trade-equity fixtures, green in CI.
3. Leasehackr adapter validated against the 3 architect vectors (offline fixtures) + manual browser round-trip (HITL).
4. Railway dev deployment at exact SHA: `/healthz` 200 with commit SHA match, `BASE_URL` e2e green against the dev domain.
5. CI green on GitHub Actions for every milestone commit.

## Non-Goals

- **Production Railway deployment + v0.1.0 tag** — requires founder HITL approval of a prod packet (owner: founder; packet format defined in F7 exit criteria). Not a hidden follow-up epic: it is an explicit decision gate.
- v0.1.1+ scope (Edmunds paste parser, program library UI, embedded PostMessage bridge) — deferred by spec §3.2.
- Any scraping/fetching of Leasehackr/Rate Findr/Edmunds — prohibited by spec §0/§4.

## Active Contract

Execute F0→F7 in order. Each phase ends with its named gate green and a commit on `main`. Human checkpoints (M1a review, M3 browser validation) pause execution and are tracked in Beads. No phase starts before its blocker is closed.

## Target Environment

- **Runtime**: Railway project `lease-matrix`, environment **`dev`**, one stateless `web` service (Railpack, Node 24, pnpm via corepack, frozen install, root monorepo build, `pnpm --filter @lease-matrix/web start`, 1 replica, US West when supported, no volume/db/cron).
- **Entry point**: generated Railway dev domain → Node static server (`apps/web/scripts/serve-static.mjs`) serving `dist`, `/healthz` returning `{ok, service, commit}`.
- **CI**: GitHub Actions `ci.yml` (Node 24, frozen install, format/lint/typecheck/test/build + Playwright Chromium smoke).
- **Local**: Node 24 LTS via mise (`.mise.toml` + `.nvmrc` + `.node-version`), corepack-pinned pnpm 10.
